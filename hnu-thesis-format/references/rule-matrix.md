# Rule matrix: academic doctoral dissertations

Source labels: **Rule** is *Hunan University Graduate Degree Thesis or Practice
Outcome Writing Specification* (2025); **Sample** is the supplied 2025 layout
demonstration. PDF page means the PDF viewer page, not a printed page number.
Rule takes priority over Sample. See [sources.md](sources.md).

| ID | Requirement | Authority and exact locator |
| --- | --- | --- |
| HNU-D-01 | Use an academic degree thesis, not a practice-outcome report. | Rule PDF p. 3, §2.3; p. 4, §2.3.1 |
| HNU-D-02 | Keep the Chinese title normally within 25 characters; do not put a subtitle on the cover. A necessary subtitle may appear on the inner title page. | Rule PDF p. 3, §2.1 |
| HNU-D-03 | State purpose, methods, results, and conclusions in an independent, complete abstract; omit formulae, figures/tables, and citation numbers. | Rule PDF p. 3, §2.2.1 |
| HNU-D-04 | Supply 3–6 semantically meaningful keywords found in the thesis, and corresponding English keywords. | Rule PDF p. 3, §2.2.2 |
| HNU-D-05 | Include an introduction, thesis body, and an unnumbered standalone conclusion. The introduction normally is Chapter 1. | Rule PDF p. 4, §2.3.1 |
| HNU-D-06 | Make the introduction cover background/significance, domestic and international literature review, source, and principal research content. | Rule PDF p. 4, §2.3.1 |
| HNU-D-07 | Make the body logically structured, clear, focused, concise, and fluent. Use discipline-appropriate analysis, evidence, and design. | Rule PDF p. 4, §2.3.1 |
| HNU-D-08 | Summarize major results and explicit innovative contributions in the conclusion; address prospects, application outlook, and value. | Rule PDF p. 4, §2.3.1 |
| HNU-D-09 | Include at least 100 directly cited references, at least 40 of them foreign-language references. | Rule PDF p. 7, §2.4 |
| HNU-D-10 | Use appendices only for material unsuitable for the body; label as Appendix A, B, C… and start each on a new page. Put a detailed Chinese abstract with Chinese title in appendices for a non-Chinese thesis. | Rule PDF p. 7, §2.5 |
| HNU-D-11 | List degree-period academic/practical achievements by type with continuous numbering. | Rule PDF p. 8, §2.6 |
| HNU-D-12 | Keep acknowledgements concise, sincere, and appropriate. | Rule PDF p. 8, §2.7 |
| HNU-D-13 | Populate the committee-list page from actual defense data only. | Rule PDF p. 8, §2.8 |
| HNU-D-14 | Write in Chinese except for foreign-language majors and international students; a non-Chinese doctoral thesis needs a detailed Chinese abstract of at least 8,000 characters in the appendices. | Rule PDF p. 9, §3.1 |
| HNU-D-15 | Write at least 50,000 characters for an academic doctoral thesis. | Rule PDF p. 9, §3.2 |
| HNU-D-16 | Put Chinese before English for inner title pages and abstracts; begin each English part on a new page. | Rule PDF p. 9, §3.3 |
| HNU-D-17 | Target about 1,200 Chinese characters for the doctoral abstract; do not repeat the thesis title on the abstract page; make English and Chinese abstracts fully equivalent. | Rule PDF p. 9, §3.4 |
| HNU-D-18 | Include all chapter titles/pages in the contents, plus needed lists of figures/tables and symbols, references, appendices, achievements, acknowledgements, and committee list. | Rule PDF p. 10, §3.5 |
| HNU-D-19 | Start each body chapter on a new page; use concise headings, normally no more than 15 characters, no punctuation, and avoid nonstandard English abbreviations. | Rule PDF p. 10, §3.6 |
| HNU-D-20 | Use page-specific circled-Arabic footnotes only when appropriate for humanities theses. | Rule PDF p. 10, §3.7 |
| HNU-D-21 | Standardize terminology and define non-common English abbreviations at first use. | Rule PDF p. 11, §3.8 |
| HNU-D-22 | The HNU Rule cites `GB3100-3102-86` for legal units and consistent quantity symbols; use italic type for physical quantities and upright type for units. Treat this as HNU source wording and manually confirm current applicable unit standards; do not claim full current-standard compliance from an automated check. | Rule PDF pp. 11–12, §§3.9–3.10; see Sources: time-sensitive units note |
| HNU-D-23 | Use Arabic numerals except where Chinese numerals are customary; write all four digits of years. | Rule PDF p. 12, §3.11 |
| HNU-D-24 | Center equations and number by chapter, e.g. (1.1); number Appendix A equations as (A.1). | Rule PDF p. 12, §3.12 |
| HNU-D-25 | Use three-line tables without left/right borders; number tables by chapter, place centered table number/title above, and use no punctuation in a table title. | Rule PDF p. 12, §3.13 |
| HNU-D-26 | Number figures by chapter; place figure title below; cite reused figures; keep each figure and title together. | Rule PDF p. 13, §§3.14.2–3.14.3 |
| HNU-D-26A | Apply applicable national/professional drawing standards and label every numeric coordinate axis. | Rule PDF pp. 13–14, §§3.14.1, 3.14.4 |
| HNU-D-27 | The 2025 HNU Rule names GB/T 7714-2015 and requires sequential numeric citations in square brackets, repeated-number reuse, and hanging indent. Confirm the current HNU/college citation instruction before formatting a live thesis. | Rule PDF p. 14, §3.15; see Sources: time-sensitive standards note |
| HNU-D-28 | List all authors up to three; for more than three, list the first three then “等” or “et al.”. Keep any approved disciplinary convention consistent throughout. | Rule PDF p. 14, §3.15 |
| HNU-D-29 | Use A4; margins top/bottom 25 mm and left/right 30 mm; header/footer distance 10 mm; line spacing 20 pt. | Rule PDF p. 18, §4.1 |
| HNU-D-30 | Apply the prescribed hierarchy, body, reference, table, header, and footnote type settings. | Rule PDF p. 18, §4.2; Sample PDF pp. 9–11 |
| HNU-D-31 | Start headers at Chinese abstract; use the official dissertation label on odd pages and the authorized thesis title on even pages, with Roman then Arabic centered page numbering. Interpret the source’s “15 pt” double-line wording through rendered verification; see Layout. | Rule PDF pp. 18–19, §4.3; Sample PDF pp. 9–10 |
| HNU-D-32 | Place the official originality statement and copyright authorization together on one page immediately after the inner title page; use handwritten signatures on paper and a handwritten-signature scan in electronic files. | Rule PDF p. 19, §4.5; Sample PDF p. 7 |
| HNU-D-33 | Use an automatically generated contents list only after setting outline levels, then adjust its format. Avoid a heading as the last line of a page. | Rule PDF p. 19, §§4.7–4.8 |
| HNU-D-34 | Place equation number at right; break long equations preferably at equals, otherwise at an operator; explain a physical quantity at first appearance. | Rule PDF p. 19, §4.9 |
| HNU-D-35 | Follow required one-sided starts and duplex printing order for front matter, body, end matter, and committee page. | Rule PDF p. 20, §4.10 |
| HNU-D-36 | Apply this rule to degrees sought in 2025 or later; defer to newer national, Ministry of Education, or HNU policy when inconsistent. | Rule PDF p. 21, §5 |
| HNU-D-37 | Use the current official cover and bilingual inner-title layouts; treat degree labels and attachment annotations in a sample as placeholders, not literal output. | Rule PDF p. 19, §4.4; Sample PDF pp. 1–6 |

**Conflict note.** Sample PDF p. 9 annotates 3–8 keywords. That conflicts with
HNU-D-04, whose controlling Rule PDF p. 3 states 3–6. Use **3–6**.

**Visual-aid limits.** Sample PDF pp. 10 and 17 show the university label on an
even page, but HNU-D-31 requires the thesis title there. The Sample’s committee
list on p. 25 is a factual record and not a model for scholarly three-line-table
automation. Its end-matter contents styling is illustrative only; apply the Rule
PDF p. 19, §4.7 and the current official template where those differ.
