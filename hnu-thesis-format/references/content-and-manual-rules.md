# Content and manual rules

Use this reference with the rule IDs in [rule-matrix.md](rule-matrix.md). It
covers an **academic doctoral dissertation** only.

## Build order

1. Chinese cover and Chinese inner title page.
2. English inner title page on a new page.
3. Official originality statement and copyright authorization together on the
   next single page.
4. Chinese abstract and 3–6 keywords, then English abstract and corresponding
   keywords on a new page.
5. Contents and any necessary lists of figures/tables or symbols/abbreviations.
6. Chapter 1 introduction, remaining body chapters, then an unnumbered conclusion.
7. References, appendices, degree-period achievements, acknowledgements, and
   committee list, each with the required page-start/printing treatment.

This sequence combines Rule PDF pp. 7–10, §§2.5–3.6 with the sample's visual
sequence on Sample PDF pp. 12–25. It does not authorize copying sample data.

## Content checks

- Make the title accurately represent the principal content; keep a cover free
  of subtitle (HNU-D-02).
- Require a standalone abstract with purpose, methods, results, and conclusion;
  do not let it become a table-of-contents summary (HNU-D-03).
- Make Chinese and English abstract meaning fully equivalent; perform a
  sentence-level equivalence review, not merely a word-count check (HNU-D-17).
- Put the required elements in the introduction and make the conclusion state
  genuine contribution, value, prospects, and future work (HNU-D-05 to HNU-D-08).
- Include only directly cited, verifiable references. Count foreign-language
  entries separately before claiming HNU-D-09 compliance.
- Do not put raw data, derivations, code, or supporting material into appendices
  by default; use the appendix only when it does not fit the narrative (HNU-D-10).

## Section and object conventions

- Apply chapter numbering only to the body. Keep “结论” unnumbered (HNU-D-05).
- Apply chapter-based numbering consistently: equation `(chapter.sequence)`,
  table `表 chapter.sequence`, and figure `图 chapter.sequence` (HNU-D-24 to
  HNU-D-26).
- Keep table titles above and figure titles below. Do not split a figure and its
  title across pages. Use a three-line table unless an auxiliary line is needed.
- Define a non-common abbreviation on first appearance; check terminology,
  quantity symbols, units, numeral form, and font style globally (HNU-D-21 to
  HNU-D-23).
- Review quantities, symbols, and units manually against the current applicable
  standard. A formatting script can identify inconsistent tokens, but cannot
  certify semantic unit compliance (HNU-D-22).
- Treat the committee list as a post-defense factual record, never as a draft
  filled from a sample (HNU-D-13).

## Manual preflight

Before export, check title length, abstract character target, 3–6 keywords,
50,000-character minimum, reference totals, foreign-language reference total,
chapter starts, heading punctuation/length, citation sequence, and appendix
lettering. After export, check the rendered PDF visually for all layout rules.
