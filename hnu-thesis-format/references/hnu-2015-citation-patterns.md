# Synthetic HNU-2015 citation patterns

Use sequential numeric citations in square brackets and a matching hanging-
indent reference list. Reuse the original number when citing the same source;
use `[2,3]` or `[2-4]` for multiple sources. These are synthetic patterns, not
source examples. They reflect the GB/T 7714-2015 reference named by the 2025 HNU
Rule; they are **not** a claim that GB/T 7714-2015 remains the current national
standard or that every pattern conforms to GB/T 7714-2025.

## Time-sensitive gate

The official national registry records GB/T 7714-2015 as abolished and GB/T
7714-2025 as current/effective 2026-07-01. Before generating or changing real
references, obtain the current HNU/college requirement and record its source.
Do not silently substitute GB/T 7714-2025 for the HNU Rule or claim 2025-standard
coverage from this reference. This file is report-only source context until that
institutional decision is confirmed.

| Type | Pattern |
| --- | --- |
| Journal | `[n] 甲作者, 乙作者, 丙作者, 等. 文章题名[J]. 期刊名, 2025, 12(3): 45-58.` |
| Journal (English) | `[n] Author A, Author B, Author C, et al. Article title[J]. Journal Title, 2025, 12(3): 45-58.` |
| Book | `[n] 甲作者. 书名[M]. 出版地: 出版者, 2025.` |
| Conference paper | `[n] 甲作者. 文章题名[C]. 论文集名. 出版地: 出版者, 2025: 45-58.` |
| Dissertation | `[n] 甲作者. 论文题名[D]. 保存地: 保存单位, 2025.` |
| Technical report | `[n] 甲作者. 报告题名[R]. 报告地: 报告单位, 2025.` |
| Patent | `[n] 权利人. 专利题名: 专利号[P]. 2025-01-01.` |
| Standard | `[n] 主要责任者. 标准编号, 标准名称[S]. 出版地: 出版者, 2025.` |

List every author if there are at most three. For more than three, list the first
three then `等` in Chinese references or `et al.` in English references. Maintain
one approved convention throughout the dissertation. Source: Rule PDF pp. 14–17,
§§3.15–3.15.7.
