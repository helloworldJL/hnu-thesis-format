# hnu-thesis-format v1.0.1

## English

`v1.0.1` is a documentation-integrity patch. It corrects the public sanitized
synthetic smoke transcript so that it shows the required
`hnu-thesis-format` working directory and the validator output actually observed
during capture. No formatter, validator, rule, privacy, or command-line behavior
changed.

The corrected transcript remains privacy-safe: local artifact paths are represented
by shell variables, while all nine decision-relevant warning/info lines are retained.
See the [corrected command log](../evidence/v1.0.0-command-log.md) and the complete
[v1.0.0 verification record](../verification.md).
