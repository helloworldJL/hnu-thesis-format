## Synthetic workflow / 合成工作流

The formatter and validator both exited 0 on a six-section synthetic academic
doctoral dissertation. The source and output were distinct, and the title entered
through an ignored UTF-8 title file. The default JSON report and the HTML report
rendered with bilingual interface labels contained no source path, input
filename, document excerpt, or synthetic private title. The output retained all
four document field instructions, bold and
superscript runs, a deliberately blank table cell, and two unrecognised tables.
Exactly one positively recognised scholarly table was formatted.

格式化器与校验器在一份六节、完全合成的学术学位博士论文上均以 0 退出。输入与输出
路径不同，题名经被忽略的 UTF-8 文件传入；默认 JSON 报告和采用中英文界面标签的
HTML 报告均不含源路径、输入文件名、正文摘录或合成私密题名。输出保留全部四个域指令、粗体与上标、一个刻意
留空的表格单元格和两张未识别表格；仅一张被明确识别的学术表格被格式化。

The HTML report was opened at 1440 by 1100 pixels. Summary cards, long statistic
values, links, and the findings table remained readable without overlap.

HTML 报告按 1440 × 1100 像素打开检查；摘要卡片、较长统计值、链接与问题表均可读，
未发生重叠。

## Rendered-document review / 渲染文档检查

LibreOffice produced a non-empty 12-page A4 PDF. A complete contact sheet and
full-resolution samples from the Chinese abstract, first body page, and final
committee page were opened and inspected. The review observed:

- no clipped or overlapping text;
- Roman numbering across the abstract/front-matter sequence and Arabic numbering
  beginning with the body;
- alternating thesis-title and university headers with the intended thick-over-
  thin rule;
- a readable three-line scholarly table whose blank cell remained blank;
- unchanged layout and committee tables; and
- preserved body emphasis and superscript formatting.

LibreOffice 生成了非空的 12 页 A4 PDF。检查者打开了全页联系表，并以原分辨率查看
中文摘要、正文首页和末尾答辩委员会页。观察结果为：无文字裁切或重叠；前置部分采用
罗马页码，正文从阿拉伯数字开始；论文题名与学校页眉按奇偶页交替，页眉为上粗下细
双线；三线表可读且空白单元格仍为空；布局表和委员会表未被改写；正文强调和上标均
得到保留。

This synthetic render is evidence that the command surface works; it is not a
claim that an individual dissertation is submission-ready. Final review must use
the current HNU and programme requirements in the required Microsoft Word
environment.

该合成渲染仅证明命令流程可以运行，不代表任何具体论文已经达到提交要求。最终检查
仍须依据当期学校与培养项目要求，并在指定的 Microsoft Word 环境中完成。
